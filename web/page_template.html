你问的三件事

为什么只有两个轮子

改成了三个全向轮。底盘现在能横着走，站位偏了可以平移修正，也能绕到物体的任意一侧去夹。仿真里的轮子带 48 个真实的小滚子，靠摩擦驱动，不是画出来的。

自由度不够

换成 SO-101：肩部水平旋转、肩抬、肘、腕俯仰、腕旋转，再加夹爪。仿真也查出它仍然缺一个腕部偏航，所以长条形物体要靠底盘绕到窄边一侧，这一点已经写进控制器。

怎么保证落地

保证不了，但可以把风险量出来。硬件全部是能买到的套件；仿真用官方物理模型和真实舵机力矩上限；每个仿真数字在下面的验收表里都对应一项你能在桌上做的实测。

整机任务：随机摆 5 件东西，全程自主

每次试验随机摆放积木、网球、遥控器、玩具车、卷好的袜子各一件，再随机加 0–2 个纸箱。机器人从没有地图开始，自己建图、找物体、夹起来、送进收纳筐，限时 10 分钟。

物理仿真查出来的七件事

这些都不是事先想到的，是跑出来才看见的，其中几条在真机上会原样出现。控制器前后改了三轮，每轮都用同一批随机布局重跑：

{{ROUND_ROWS}}
标准条件，20 次试验送达碰撞机身倾斜超过 3° 的试验最大倾斜
  1. 夹爪必须贴防滑胶带不贴的话网球 {{BARE_BALL}} 成功，贴了是 {{TAPE_BALL}}。整机试验里不贴胶带的送达率从 {{STD_PCT}} 掉到 {{BARE_PCT}}。
  2. 夹爪要歪着下去摆动式夹爪张开时两个指尖不一样高，垂直往下夹扁的东西会一边压住一边够不着。把夹爪倾斜半个张角，两个指尖才齐平。第一版仿真遥控器 0/4，改后 {{TAPE_REMOTE}}。
  3. 5 轴臂要靠底盘补一个自由度没有腕部偏航，夹爪只能沿肩到物体的连线开合。控制器让底盘先绕到长条物体的窄边一侧再伸手。
  4. 雷达会把自己夹着的东西当成墙搬运时物体正好在雷达扫描面上，机器人以为前方 20 cm 有障碍，原地打转了 50 秒。加了机身范围滤波后消失。真机一定会遇到同样的问题。
  5. 手臂有力气把整台车撬起来整机只有 {{ROBOT_MASS}} kg。第一轮 20 次标准试验里有 10 次机身被顶起超过 3°：夹爪落在没摆正的物体上往下压，或者绕去物体另一侧时从它身上碾过去。现在夹爪按物体实际横宽张开，下探时一旦机身抬起就收手，着地时先用 0.4 N·m 轻合，路径也会绕开目标本身。这一轮是 {{STD_TILT}} 次。
  6. 只照着地图开会撞第二轮有一次，机器人按自己的地图规划，径直开进桌角并翻倒。地图在那一处没有标出障碍，是被擦掉了还是落进了机身滤波的盲区，我没有完全查清。现在加了一层不看地图、只看当前这一圈雷达的防撞，并把机身滤波的范围缩到刚好罩住手臂。
  7. 舵机指令要插值机械臂按 50 Hz 给台阶式位置指令时，电机有四分之一的时间顶在力矩上限的 80% 以上。改成按毫秒插值、限制加速度后降到 1% 以下。

哪些是真物理

  • 轮子、滚子和地面的接触与摩擦，底盘靠摩擦力前进。
  • 舵机力矩上限 2.94 N·m（STS3215 12 V 堵转值），转速上限由官方模型的阻尼给出。
  • 机械臂的质量、惯量、关节限位，来自 SO-101 官方模型。
  • 夹爪与物体的接触：夹不稳会滑、会掉、会被碰倒。
  • 雷达：240 线射线投射，1 cm 噪声，会被自己的手臂挡住。

哪些是假设

  • 定位：真实位姿加 1.5 cm / 1° 的慢变噪声，代替激光定位算法。
  • 识别：相机视野内且不被遮挡的物体一定认得出、不认错，位置带 5 mm + 1.5% 距离的噪声。
  • 收纳筐位置事先告诉机器人。
  • 底盘、电池等的重量是估的（整机约 2.35 kg），滚子没有轴承间隙。
  • 打印件不变形、舵机没有回差、袜子用一个偏软的椭球代替。

这些假设每一条在验收表里都有对应的实测项。测出来不一样，就改参数重跑。

自己跑一遍

git clone https://github.com/ahoo/xiaoshi-robot
cd xiaoshi-robot
pip install mujoco numpy scipy imageio imageio-ffmpeg pillow
cd sim
python test_base.py        # 底盘台架
python test_grasp.py 10    # 抓取台架
python episode.py 4        # 一次完整试验，打印事件日志
python run_trials.py       # 全部随机试验
python render_video.py 4   # 生成录像

硬件参数集中在 sim/model.py 顶部的 P，传感器噪声在 sim/controller.py 顶部。实测后改这两处重跑。

还没做的

  • 没有跑真的识别模型和真的激光定位，这两块目前是带噪声的理想传感器。它们是实物上最可能拉低成功率的地方。
  • 没有模拟会动的障碍（人、宠物），也没有地毯、门槛。雷达扫描面离地 20 cm，比这矮的障碍只能靠相机。
  • 贴墙 12 cm 以内的物体没有测；长条物体窄边朝墙时现在会直接放弃。
  • 样本量不大：标准条件 {{STD_N}} 次，其他条件 {{OTHER_N}}。差几个百分点不要当真。
  • 第一版的概念演示页保留在仓库 web/concept-v0.1/，它不是物理仿真，仅作对照。
