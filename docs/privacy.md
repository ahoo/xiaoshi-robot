# 小拾：家里的隐私与孩子的数据（设计规则，第十四轮）

这是一份**工程上的设计规则**，说的是代码现在怎么做、实物上必须怎么做，不是法律意见。机器人只在你自己家里用，不对外销售，这份规则就是够用的底线；如果以后要卖给别人，面向孩子的数据处理要请专业人员审一遍（见最后一节）。

## 一句话

**本机处理、默认不存、认人要大人同意、随时能删、什么都不往外传。**

## 机器人会碰到哪些数据

| 数据 | 在哪里处理 | 存不存 | 存多久 / 谁能删 |
|---|---|---|---|
| 麦克风声音 | 唤醒词（“小拾小拾”）和停止词（“停”“别动”）在机器人本机识别 | **不存**。唤醒之前的声音不做任何处理，更不往外发 | 不存，没有可删的 |
| 说过的命令（文字） | 本机 | 默认**不留**；打开 `keep_transcripts` 才会在内存里的会话日志里留文字（现在代码里没有写盘的地方；实物上要决定写不写、留多久） | 重启就没了；真要写盘就是本机文件，你自己删 |
| 摄像头图像 | 深度图和彩色图只在内存里用，用完即丢 | **不存图像**（物件记录里只有 12 维颜色直方图、尺寸、位置） | 随物件记录 |
| 三维地图 | 本机 | 存（本机 JSON / PLY）；里面是体素和颜色，认不出人 | 你自己删文件 |
| 物件记录 | 本机 | 存（本机 JSON）：名字、种类、尺寸、颜色直方图、位置、看到的时间 | 说“忘掉……”或删文件 |
| **没登记的人** | 内存里一条临时轨迹（位置、身高、大人/小孩）；安全层另外记着“刚才有人站在那里”的位置（只有位置和是不是小孩，站着不动的最多记 90 秒，走动的 8 秒），用来不往那里去拿东西 | **不存盘**，轨迹 3 秒没看到就消失；**永远不给没登记的人起名字** | 自动 |
| **登记过的人** | 本机的登记簿 | 存：名字、角色、**一个特征向量**（不是照片）、谁同意的、什么时候 | 说“忘掉小明”或“忘掉所有人”，当场删，找不回来 |
| 大模型（可选，默认关） | 只发文字 | 见下 | 见下 |

## 孩子

1. **默认只分大小，不认人。** 孩子进了房间，机器人用头部相机量出身高，分成“小孩 / 大人 / 不确定”（不确定一律按小孩对待），用来放慢、停下、手臂不动；这一步没有任何身份信息，也不存任何东西。
2. **认出是哪个孩子是可选的，而且要大人同意。** 流程在 `sim/voice.py`：大人说“记住这个孩子，他叫小明”→ 机器人确认名字 → 机器人说清楚存什么、存在哪、怎么删 → **大人**说“同意”→ 让孩子看着机器人几秒 → 存特征向量。**孩子自己说“同意”不算**（测试里孩子说同意会被拒绝）。
3. **不存照片。** 存的是一个 24 维（仿真里的替身）或几百维（真实模型）的数字向量，不能还原成人脸，但仍然是**生物识别信息**，按敏感信息对待：只存在机器人上，不上传、不备份到别处。
4. **说话的人是孩子时，权限收窄**：可以问东西在哪、让它收玩具、喊停、问状态；**不能**让它记人、忘人、去充电、扫描全屋、跑到房间另一头；这些要大人说。孩子的话不进大模型的自由聊天（见下）。
5. **身份只用来个性化，不用来放权限。** 权限看的是“说话的人是登记过的大人（主人）/ 没登记的大人 / 孩子或看不清”，而且要改变机器人行为的命令（去哪、记人、忘人）还要再口头确认一次。认错人（比如两个兄弟姐妹）最多叫错名字，不会让孩子拿到大人的权限：孩子的身高类别会让他落在“孩子”这一档，除非登记簿里他被登记成大人。
6. **兄弟姐妹长得像、声音像**，是识别最容易错的地方。仿真里兄弟姐妹共享特征的一部分，要求最高分过线并且比第二名高出一截，否则输出“不认识”（见 `results/home_people_identity.json`）。真实模型要在你自己家的孩子身上量，不能用仿真的数字。
7. 法律上：《个人信息保护法》把生物识别信息和不满十四周岁未成年人的个人信息都列为敏感个人信息（第二十八条），处理不满十四周岁未成年人个人信息要取得监护人同意并有专门的处理规则（第三十一条）。放在自己家里、由监护人亲自登记和管理，是最简单的合规做法；以上是对条文的一般性提示，**不是法律意见**。

## 声音和大模型

- 常开的只有**唤醒词和停止词识别**，在机器人本机上跑（比如 sherpa-onnx 一类的小模型，实物上要选型验证）。唤醒词故意用四个音节“小拾小拾”，因为“小拾”和“小时”同音，会被家里的每一句话叫醒（`results/home_voice.json`：没喊唤醒词的 576 句家里闲聊，0 句被当成命令）。
- **停止词不要唤醒词**，任何人都能喊：“停”“停下”“别动”“站住”“救命”，仿真里 96.5%~100% 被听到（成年人和孩子，安静和吵闹），闲聊里误停 0 次。
- 机身要有**硬件静音键**，按下去麦克风断电，不是软件假装不听；语音说“静音”“别听了”也行，但**只能按键重新打开**。摄像头同理，要有物理遮挡或断电开关和一个看得见的指示灯。
- 大模型是**可选**的，默认不开。开了以后：只发**说话内容的文字**（不发声音、不发图像、不发人名，除非主人另外允许）；它**只能提议**一个固定列表里的动作或一句话，提议的动作和别的命令一样要过权限检查和口头确认（动作类、记人类的永远要再问一次）；孩子说的话默认**不**交给它做自由聊天；它超时或胡说就退回“我没听清”。仿真里只能测这条接口（`MockLLM`），不能测真实模型怎么理解和回答。

## 实物上必须做到的（验收表里要加的项）

1. 抓包：唤醒词之前、没开大模型时，机器人**没有任何对外网络请求**。
2. 数据盘检查：运行一天后，机器人上**找不到任何图片或音频文件**。
3. 登记簿是一个人能读的本机文件；“忘掉小明”之后文件里没有小明；机器人重启后仍然不认识。
4. 用家里孩子试（经监护人同意）：认对率、认错率（把一个孩子认成另一个）、不认识的访客孩子被拒绝的比率；**拿照片、视频放在机器人前面试能不能被骗过**（仿真测不了）。
5. 静音键按下后，用示波器或功耗看麦克风确实断了。

## 还没做、要你决定的

- 要不要让机器人在**别人（访客）**在场时提醒“我在看着，你们可以说‘静音’”？（默认没有）
- 日志里要不要保留命令文字，保留多久。
- 记人时要不要**同时给孩子的监护人推送一条通知**（需要手机端，现在没有）。
