# 仿真功能验收

这份验收回答一个问题：**在仿真里，机器人要有的每一项功能，各自做到了没有。** 每一项有一个场景、一条写死的通过标准、一条命令；结论是自动算出来的。
物料等这份验收满意了再备（实物验收见 [`validation.md`](validation.md)，那是买了硬件以后做的）。

## 怎么跑

```bash
cd sim
python accept.py --list                    # 有哪些项、各自的标准和命令、大概多久
python accept.py --report                  # 用 results/ 里已有的结果下结论（几秒钟，什么都不跑）
python accept.py --run quick                # 重跑每项几分钟的那些（约 40 分钟，4 核），在临时副本里跑，不动 results/
python accept.py --run standard             # 重跑全部（约 3 小时，4 核）
python accept.py --run quick --only C3,F5  # 只跑指定的几项
```

`--run` 会在临时目录里放一份仓库的副本再跑，所以 `results/` 里已有的结果不会被改；跑完把结论和数字写进 `results/acceptance_sim.json` 和这个文件（只有验收自己用的 `accept_job.json`、`accept_day2.json` 会留在 `results/` 里，这样 `--report` 才有东西可判）。标准写在 `sim/accept.py` 的 `ITEMS` 里，改一个数字，结论就跟着变。

- **标准**：安静时：登记的人被认成别人 ≤ 1%；访客被叫成家人 ≤ 3%；等错误率 ≤ 12%
- **命令**（约 5 分钟，quick）：`python test_sound.py voiceprint`
- **仿真证明不了的**：声纹模型是我们自己训练的小模型（等错误率 9%）；真的神经网络嵌入、感冒、兄弟姐妹、孩子变声要在真人身上量（验收表第 56 项）
- **要注意**：访客被叫成家人 1.6%（通过线 3%），等错误率 9.1%（通过线 12%）；声纹只当弱证据，不单独放权限。
- **实物验收表里对应的**（[`validation.md`](validation.md)）：第 56 项

### G3 声音和人对上号，权限借不走

- **场景**：200 个随机房间：登记的人、访客、视野外的人、电视开着、电视喊唤醒词、电视放主人的录音
- **标准**：访客和电视（喊唤醒词、放主人录音）拿到“主人”权限 0 次；视野外的人被算到视野里某个人头上的 ≤ 5%，其中拿到“主人”的 ≤ 2%
- **命令**（约 5 分钟，standard）：`python test_assoc.py assoc 200`
- **仿真证明不了的**：电视和访客是仿真里编出来的；声纹被电视里的录音骗过 40%，所以权限不靠声纹（验收表第 57、58 项）
- **要注意**：第一遍读的是存下的结果（旧代码），电视放主人的录音拿“主人”权限是 0%；重跑 200 个房间时有 2 个房间（17 号、145 号）拿到了：电视没学会（92% 的房间学会了，这 2 个在没学会的 8% 里），电视的方向和那个“主人”在视野里的方向差 36–37°（方向估计的 σ 是 14°，约 2.6σ），声纹被录音骗成“是他”，融合把这个声音算给了视野里的那个人，而“主人”的条件里没有单独检查“人在声音的方向上”。已改（`assoc.py` 一行：“主人”还要求这个人在声音方向的 2σ 以内，否则只给“大人”），这两个房间不再拿到主人，其余统计一个数都没变。要注意：① 声纹被电视里的录音骗过 43%，现在只是没让它拿到“主人”这一级，“大人”那一级拿到 7%（防重放只防住了权限，没有活体检测）；② 电视没学会、又正好在主人的方向上时，录音和真人靠方向分不开，这 200 个房间里没出现，但原理上还在。
- **实物验收表里对应的**（[`validation.md`](validation.md)）：第 57、58 项

## 通过这份验收，说明什么、不说明什么

**说明**：我们自己写的那部分（控制、感知、建图、对话、权限、隐私、模式切换、起身、充电、安全层）在仿真里按上面的标准做对了，而且每次改代码都能一条命令重新验。

**不说明**：真机上也这样。仿真里声音是合成的、人脸识别是替身、深度相机和舵机是模型、大模型没有对真服务测过、物体和房间是简化的。验收表（[`validation.md`](validation.md)）里买了硬件以后要逐项量的，这里都标在“仿真证明不了的”里；其中风险最大的几项是：起身（实物最冒险）、真人脸模型和真声纹模型的准确率、唤醒词的命中率和误唤醒、透明瓶在真深度图上的信号。
